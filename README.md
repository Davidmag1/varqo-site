## Positioning and scope

- Varqo is an enterprise integrity layer for autonomous AI workflows.
- The current proven kernel independently verifies resulting provider state and can hold dependent execution until required evidence is available.
- The R&D direction is automatic verification planning: derive testable conditions from available task and action context, build paths to authoritative evidence, and challenge candidate plans with controlled counterexamples.
- Action-level verification can often be grounded in the tool call, parameters, interface schema, and documentation. Claims that an entire enterprise process is complete also require an authoritative source for organization-specific obligations.
- A narrow restart path is lab proven. Generic recovery and a durable enterprise evidence history independent of the agent chat remain product direction.
